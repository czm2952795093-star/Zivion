# 使用 Zivion

填写日期、时辰、性别和经度后起盘。可保存命例、记录笔记或复制盘面文字。

输入阴历出生日期时，勾选“阴历”后点击“调整时间”。选择器按年份提供实际闰月与月天数，可分别调整时分秒。切换年、月可能调整闰月和日期，请核对底部提示后填入；填入会保存草稿，取消保留原输入。点击起盘才更新命盘。

在命盘下方选择本命、大限、流年或流月；使用虚岁、按年份或月份控件定位。流月支持选择农历日与时辰，也可通过“公历换算”辅助填写。

公历换算以东八区钟表时间为准。普通日期可填入叠宫；闰月与23点只显示结果。手选日期按非闰月天数检查，不能将闰月当作同名普通月。

应用可继续上次命盘，同时保留尚未起盘的输入草稿。备份与恢复支持本应用的数据格式，不含查询显示设置；恢复会合并记录并跳过相同项。命例、历史和笔记每类最多5000条。卸载前请导出备份。

输入页的“显示秒”会更新输入日期提示与盘面时间显示。命盘、复制与读屏说明会标明闰月；开启“隐藏时间”可隐藏这些位置的出生日期，输入草稿仍可正常编辑。

在大限、流年或流月模式点击“流曜分布”，可查看和复制限年分布。勾选“盘面复制含流曜”后，盘面复制会附上分布。

点选宫位可在下方查看该宫的流曜。再点同一宫可打开详情。
