# 紫微星语复刻验证版 0.14.0

流月新增“公历换算”：输入14位公历年月日时分秒，查看农历年、月、日、时辰及当月天数；确认后可同时填入年份、月份和日时叠宫，不用手工查农历。

## 时间与适用规则

采用东八区钟表时间、午夜换日，不按出生地经度修正真太阳时。换算范围1901—2100年。闰月及23点可显示普通历法结果，但因原版相应叠宫规则尚未确认，暂不允许填入；可取消返回原盘。年份超出当前命盘1—120虚岁范围也不填入。

普通日期填入前先完成全部校验，再一次性切换查询年月日时并回到默认四化来源。出生信息和原盘事项保持不变，不新增历史；重启可继续填入后的叠宫。填入的是既有手选日时层，因此摘要仍明确显示“手选日时”；不会自动随当前日期推进，不产生日时四化或流曜。之后再手动修改日序仍未校验该月有效天数。

## 证据和验证

历表由已使用的lunar-typescript 1.8.6生成，新增独立CalendarLookup，不修改本命计算引擎。香港天文台2025、2026年逐日CSV共730个日期作为独立对照，分别检查00:00、12:00和23:59:59，验证农历年/月/日/闰月。共13185项程序检查通过，还覆盖时辰、非法日期、历表连续性、范围端点与设备默认时区变化。检查条数不等于原版样本数，1901—2100全范围尚未逐日官方对照。

官方数据：[2025年](https://data.weather.gov.hk/weatherAPI/hko_data/calendar/nongli_calendar_2025.csv)、[2026年](https://data.weather.gov.hk/weatherAPI/hko_data/calendar/nongli_calendar_2026.csv)。取数日期及文件摘要见rea-evidence/v14/sources.json。远期日历存在预测边界，参见[香港天文台对照表说明](https://www.hko.gov.hk/sc/gts/time/conversion.htm)。

Android9/API28离线模拟器验证预览取消、完整填入、非法日期、闰月/23点限制、超出年龄、春节年界、重启恢复及升级记录保留。完整结果见calendar-ui-test.json。REA安装/拉取核验通过，签名沿用0.13.2；本命引擎字节一致，没有重跑全部原版本命对照或新增真机验证。

本次复用REA确认的月→日→时宫位位移，详见既有v12-research/DAY_HOUR_ENTRY.md；没有新取原版日期协议运行样本，不把独立民用历法一致称为原版自动日时排盘完全一致。原版闰月/子时/太阳时规则、流曜、其他精度与工具和界面差异仍待完善。
