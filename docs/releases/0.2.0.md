# 紫微星语复刻验证版 0.2.0

本版继续按 REA 的原版拆解证据完善，可安装并离线运行。尚未达到原版全部界面和算法完全一致。

## 本次变化

- **命例、历史和笔记备份**：输入页点击“备份与恢复”，选择系统文件位置导出 JSON；恢复时先显示记录数量，再合并。保留当前记录，相同的导入内容跳过；已有重复历史不会被删除。损坏文件在写入记录前被拒绝。备份不包含显示设置，不兼容原版的专有备份文件。
- **修正“换月”默认设置**：新安装默认关闭，与原版默认状态一致。2012-06-12 18:00、女、东经120°的原版闰月样本中，命宫为申、身宫为寅，复刻版现在按该设置匹配。升级保留已有选择和已保存命例中的选择；如果旧版已开启，需要手动取消勾选后重新排盘。
- **部分庙旺显示校准**：使用9个原版样本中重复出现、没有冲突的124个“星曜＋地支”组合。另用3个未参与校准的样本检验。没有可靠观察的组合仍采用独立库结果，没有把单个命盘硬编码为通用算法。
- **输入和显示**：输入时间下方同步显示年月日时分，切换阴历后文字随之更新；调整输入行和按钮宽度，增加命盘时间“显示秒”开关。

## 原版对照

REA 实际用于安装和截图，原版 APK 未修改。12份原版命盘文字来自其公开“复制盘面”功能，由受控模拟器辅助导出。样本覆盖1965至2024年的不同日期、男女、时辰，以及公历闰日、阴历闰月；本轮均为东经120°、东八区、公历输入、关闭换月，尚未覆盖全部边界。

| 项目 | 本轮结果 |
|---|---|
| 宫位名称、宫干、大限 | 12份样本均为各12项匹配，交友/仆役按别名归一比较 |
| 14主星落宫 | 12份样本均为14项匹配 |
| 各宫四化星及去向 | 12份样本均为48项匹配，不包含原版力度百分比 |
| 留出3份样本的共同星曜庙旺 | 匹配由46/188提高至94/188；仍有94项差异，计数包括空白显示 |
| 校准表命中的留出样本组合 | 未发现与原版冲突；不能据此保证所有日期一致 |

详细原始文字、样本角色、REA截图证据和差异列表保存在 `验收记录-0.2.0/`。这些是有限样本观察；124个组合的显示适配是依据观察推导的部分规则，不是取得了原版算法源码。

## 验证

- Android 9 / API28、x86_64、720×1280模拟器，关闭Wi-Fi和移动数据，实际覆盖安装0.1版并保留旧命例和笔记。
- 系统文件选择器实测：导出、取消恢复、合并新增记录、重复恢复、拒绝含无效记录的文件，以及恢复后重启持久保存。
- 16项备份格式/合并检查；84组跨年份、性别、时辰的命盘结构检查，以及阴阳历等价、闰月、非法日期和真太阳时输入检查。
- 12份原版样本的结构对照和3份留出样本的校准验证。
- APK签名校验；最终安装包与实测设备中拉取的包核对哈希。

## 安装与源码

`紫微星语-复刻验证版-0.2.0.apk` 与上版使用相同包名和签名，可覆盖更新。包名为 `local.ziweixingyu.rebuild`，可与原版共存。旧版安装包仍保留。

源码包包含原生安卓页面、离线计算源码、观察表、锁定依赖、构建脚本、测试和第三方许可。按源码中的 README 构建；源码包不包含交付包的签名私钥。所有计算和记录在本地，没有联网权限。

## 仍未完成

部分庙旺、杂曜、太阳时秒值、原版四化力度百分比、流运叠盘，以及字体、间距和手势细节仍有差异。AI、充值、更新、定位、六爻及其他工具页尚未实现。计算仍使用 iztro 2.6.2、lunar-typescript 与近似太阳时模型；未使用原版签名绑定的原生排盘库，也未绕过签名检查。尚未在实体手机和其他安卓版本验收。
