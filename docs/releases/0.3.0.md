# 紫微星语复刻验证版 0.3.0

本版重点补齐星曜位置规则和记录搜索。仍是验证版，尚未与原版全部算法和功能完全一致。

## 本次完善

- 修正部分生年的天魁、天钺位置，补齐龙德、大耗、劫煞、副旬，并区分截空、副截。规则依生年干支计算，不按具体出生日期读取预存命盘。
- 命例和历史支持名称、出生日期搜索；例如输入 `19900101` 可以找到 `1990-01-01` 的记录。英文不区分大小写。
- 笔记支持标题、正文搜索；可清空搜索，并显示匹配数量。筛选后打开、编辑和删除都对应原始记录，删除仍有确认。
- 记录列表使用安卓 ListView 按需创建可见行，长标题省略显示，日期另占一行。
- 保留0.2版的备份恢复、秒数显示、公历/阴历/闰月、经度及真太阳时输入等功能。

## 与原版的对照结果

使用12份既有原版命盘分析差异，再采集10份新日期验证，新增日期覆盖甲至癸十种年干及不同性别、时辰。本轮10份验证样本未用于选择新规则的日期查表项；庙旺显示仍使用0.2版的124项部分校准表，没有用新样本扩充该表。

| 对照项目 | 结果 |
|---|---|
| 星曜名称与落宫 | 22份样本，每份70颗星曜均匹配；合计1540/1540，未见缺项或额外项 |
| 新增10份验证样本的星曜落宫 | 0.2版630/700；本版700/700，额外项由30项降至0项 |
| 十二宫名称、宫干、大限 | 22份样本均为各12项匹配，交友/仆役按别名归一 |
| 14颗主星落宫 | 22份样本均匹配 |
| 各宫四化星与去向 | 22份样本均为48项匹配，不包括原版力度百分比 |
| 庙旺显示 | 22份样本合计808/1540匹配，仍有732项差异；计数包含空白显示 |

所有对照均为公历输入、东八区、东经120°、关闭“换月”。这些结果不能推广成全部日期、时区、闰月边界或流运规则都一致。

原版 APK 未修改。REA 用于实际安装、应用启动和截图；原始命盘文字来自原版公开的“复制盘面”功能，由受控模拟器辅助导出。新星曜兼容规则是依据原版输出和固定版本独立库的实现推导的规则，不是取得了原版原生算法源码。记录页搜索框的外观参照来自此前 REA 解码的 `activity_listx.xml`；笔记正文搜索是本版新增的便利功能。

## 安装和数据

安装 `紫微星语-复刻验证版-0.3.0.apk` 可覆盖更新0.1/0.2版，保留已有命例和笔记。包名仍为 `local.ziweixingyu.rebuild`，签名保持相同，可与原版共存。以前保存的命例打开时采用更新后的星曜规则重新排盘，原始出生输入保持不变。

备份仍从输入页“备份与恢复”导出或合并恢复；格式与0.2版兼容。备份只包含本复刻版的命例、历史、笔记，不含显示设置，不兼容原版专有格式。

## 验证与文件

在 Android 9 / API28、x86_64、720×1280模拟器中覆盖安装和测试，Wi-Fi及移动数据关闭。检查包括记录搜索、无结果与清空、筛选后打开及删除、笔记搜索与编辑、原有记录持久保存，以及排盘回归测试。独立引擎的84组结构检查和22份原版对照通过。原始文字、REA截图证据与测试结果保存在 `验收记录-0.3.0/`。

源码包包含安卓源文件、离线计算模块、新规则、固定依赖、构建说明、对照脚本和原始样本文字。安装包通过签名校验，并与从实测设备拉取的APK核对哈希。没有联网权限，不包含原版原生排盘库。未在实体手机或其他安卓版本验收。
