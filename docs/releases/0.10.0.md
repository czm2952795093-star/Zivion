# 紫微星语复刻验证版 0.10.0

本次加入流月的月序查询，整款APP仍未与原版完全一致。

## 新功能与使用方式

命盘下方增加“流月”。设定虚岁后，可选择正月至腊月，或按“上月 / 下月”切换。正月向前、腊月向后会停在边界，不自动换年；使用虚岁调整所查年份。

流月页面同时保留大限、流年宫位，并显示所选月份的月宫位，以及各宫对应的月份和月干。点选宫位可以查看该宫四化，“回到命宫”恢复当前月的命宫来源。切换月份、年份或模式会重置旧宫位选择，重新起盘默认正月。

标题中的“月干”描述月份干支；四化摘要中的宫干来自所选宫位，两者不强行等同。复制盘面会附加三层时期、所选四化来源及十二个月份分布。

REA保存的原版r(Canvas)读取出生时支及“农历月计数”，形成流月起点；g(Canvas)依月序排布月份、月干和月宫位；本次进一步读取o(String,int)确认地支位移顺序。月份起点依流年地支、出生时支、出生农历月份计算。

前三个年度状态复用已保存的原版截图，后四个为本次新增。共7个年度状态、84个月份位置及月干对照；设置均为公历、东八区、东经120°、关闭“换月”。这不是84份完整流月命盘验收，也未证明所有闰月、换月设置和时间边界一致。

月宫位的旋转依据静态代码，月份位置与月干由原版截图交叉核对。四化继续采用“所选宫位四化”的已确认行为；新增流月按钮、月份选择及自动选择月命宫是复刻版提供的查询入口，没有宣称完全复制原版的操作方式。

独立检查：新增1238项月份检查通过，既有1385项流运、486项来源选择检查继续通过。实际安装包在Android9/API28、x86_64、720×1280离线模拟器检查月份下拉、十二月循环、边界、跨年、选宫、复制、三层显示、首限前状态和重启。原命例、笔记及旧历史保留。

本命引擎与0.9.0字节一致，力度表468项、庙旺表552项没有改变，沿用此前84组结构和56份本命对照结果。本次不把这些本命结果计作流月验证。

## 当前限制

流月按正月至腊月的月序查看，暂不区分所查年份中的闰月，也不提供对应公历起止日期。已检查一个闰月出生样本，不等于完整支持所有闰月规则。

流日、流时、流曜、原版其他工具、复杂标记连线、部分庙旺与太阳时精度仍待完善。流月模式暂时隐藏格内小限年龄及长生文字以避免叠字，切回其他模式恢复；流运四化色块暂时代替本命生年四化色块。界面布局、默认年份和部分手势仍与原版不同。

安装包与此前复刻版使用相同包名和签名，可覆盖更新。交付APK与REA从测试设备拉取的APK一致。未在实体手机或其他安卓版本验收。

原版APK未改动，未绕过签名检查；复刻包不含原版原生算法库及联网权限。源码含证据、测试和依赖许可，不含原版APK、签名私钥或模拟器偏好文件。
