# 紫微星语复刻验证版 0.4.0

本版完善日期边界和记录保存，仍未与原版全部功能、算法及外观完全一致。

## 本次更新

- 修正已观察到的除夕晚子时、普通晚子时排盘差异。斗数生年、月日与四柱分别处理，避免把节气换年直接套在斗数生年上。
- 修复导入较多命例或历史后，再次保存会按旧上限截掉末尾记录的问题。命例、历史、笔记统一每类5000条；满额时拒绝新增并提示，已有数据保留。满额笔记仍可编辑。
- 统一备份导入、导出的 UTF-8 字节限制：最多8,000,000字节。含大量中文的备份不再按字符数误判；在打开导出文件选择器前预检。
- 保存时校验标题最多500字、笔记正文最多100000字，与备份恢复的限制保持一致。

## 与原版的对照

保留之前22份样本，新增14份春节、立春、闰月和子时边界样本。最后3份普通晚子时、早子时和另一年除夕样本在规则确定后采集用于验证；前11份参与差异分析，不应全部称为独立验证集。

| 项目 | 结果 |
|---|---|
| 星曜名称和落宫 | 36份原版样本，每份70颗均匹配；2520/2520，无缺项或额外项 |
| 新增14份边界样本的落宫 | 0.3版859/980，本版980/980 |
| 十二宫名称、宫干、大限 | 36份样本各12项均匹配；交友/仆役按别名归一 |
| 主星位置、各宫四化去向 | 每份14颗主星和48项四化去向均匹配，不含力度百分比 |
| 庙旺显示 | 1273/2520匹配，仍有1247项差异，计数包含空白显示；本次未扩充亮度校准表 |

推导规则：斗数生年在农历除夕的有效太阳时23点切换；用于安星的月日保留到午夜。四柱另用节气和子时规则。实现通过独立库的同步构盘适配层处理，执行完毕恢复库函数，不修改原版二进制。

这些结论来自有限样本；全部原版对照均为公历输入、东八区、东经120°、关闭“换月”。尚不能保证所有日期、经度、时区及其他设置都一致。太阳时本身仍为近似模型，秒值可能不同。

原版APK未修改。继续使用REA采集原版屏幕、安装运行和核验安装包；命盘文字来自原版公开复制功能，界面操作和文字提取由受控模拟器辅助完成。兼容规则是根据输出推导的独立实现，并非取得原版算法源码。

## 安装与数据

安装本版APK可覆盖更新此前复刻版，包名和签名保持一致，可与原版共存。已有命例重新打开时使用本版规则计算，出生输入不变。备份格式与0.2、0.3版兼容，只含本复刻版的命例、历史、笔记，不含设置，不支持原版专有备份格式。

## 验证范围

独立引擎84组结构检查、36份原版对照、16项备份校验和24项容量/中文备份检查通过。安装后验证在Android 9 / API28、x86_64、720×1280模拟器进行，网络关闭。详细结果保存在本版验收记录中；未在实体手机和其他安卓版本验收。

安装后另通过4项容量操作、3份晚子时命盘核对及7项原有流程检查，覆盖旧命例/笔记保留、错误日期拦截、公历闰日和阴历排盘。系统文件选择器导出的备份与当时保存的2条命例、25条历史和2条笔记逐项一致。容量测试仅使用模拟器临时数据，结束后原有数据文件逐字节恢复。

源码包包含安卓源码、独立计算模块、固定依赖、构建说明、单元测试和原版对照样本文字。安装包不含原版原生排盘库，也没有联网权限。

## 尚待完善

庙旺亮度、四化力度百分比、流运叠盘、太阳时精度，以及界面字体、间距和手势仍有差异。AI、充值、定位、六爻及其他工具页尚未完成。样本中的星曜位置匹配，不代表整个APP已一模一样。
