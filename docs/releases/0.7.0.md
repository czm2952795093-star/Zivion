# 紫微星语复刻验证版 0.7.0

本版补齐当前已识别的四化力度显示组合，仍未与原版整个APP完全一致。

## 本次完善

力度兼容表从359项扩展到468项，每项均至少在两份不同原版命盘中出现，且没有数值冲突。旧版359项已确认值保持不变。命盘下方信息、宫位详情和复制盘面使用同一份显示结果。

此前2001年11月4日14:30的测试命盘只有6项力度已确认、42项未确认；本版补齐到48项。保留对真正未知组合的提示机制，不将未知值当作0%。庙旺表仍为552项，本次没有扩充。

## 如何验证

先使用48份旧原版命盘确定哪些组合需要更多证据，再用独立计算模块选择两份能覆盖缺口的日期，实际读取原版输出确认数值。这两份属于针对性开发样本，不能算作独立验证。两份日期为1992年11月9日07:30男性、1961年1月8日06:30女性。

随后冻结468项表并保存文件哈希，再采集另外6份预先选定的新日期验证，没有使用这6份修改表。

| 对照项目 | 结果 |
|---|---|
| 6份独立验证样本的力度 | 288/288匹配，没有未确认项；0.6版在这些样本中可显示282项 |
| 50份开发样本的力度 | 2400/2400匹配；0.6版可显示2131项 |
| 56份样本的星曜名称、位置 | 3920/3920匹配，无缺项或额外项 |
| 十二宫名称、宫干、大限 | 每份各12项匹配；交友/仆役按别名归一 |
| 主星、四化去向 | 每份14颗主星及48项四化去向匹配 |
| 庙旺显示 | 开发样本3208/3500；新验证样本371/420，仍存在差异 |

这验证的是有限设置下的显示兼容，并非恢复了原版算法，也不代表所有日期、设置和流运都一致。原版对照仍限于公历、东八区、东经120°、关闭“换月”。庙旺计数包含空白显示。

## 安装和文件

包名和签名保持一致，可覆盖此前复刻版并与原版共存；原有命例的出生输入不变，打开时采用新版显示规则。原版APK未修改，没有绕过其原生签名检查，复刻包不含原版原生算法库，也没有联网权限。

REA用于原版截图、复刻安装及安装包拉取核验。文字来自原版公开复制功能，界面操作和文字导出由受控模拟器辅助完成。源码包包含56份原始样本文字、力度来源、针对性选样计划、独立验证计划及冻结哈希。

独立引擎84组结构检查和56份原版对照通过。安装验证环境是Android 9 / API28、x86_64、720×1280模拟器，网络关闭。未在实体手机或其他安卓版本验收。本轮未改动备份和保存代码，相关完整测试保留在0.4版记录中。

安装后检查1968、2032两份新命盘，以及此前力度缺项较多的2001命盘：每份70颗星曜及庙旺文字、48项四化力度均与新版计算模块一致，均没有未确认项；宫位详情的实际显示也已检查。覆盖更新前后逐项核对，已有命例和笔记完全相同，所有旧历史保留。交付包与从测试设备拉取的APK及内置计算模块一致。

## 尚待完善

流运叠盘、部分庙旺、太阳时精度、更广泛的输入边界、原版工具页和界面细节仍需继续完善。力度表覆盖本版已识别的组合，不等于整个APP已一模一样。
