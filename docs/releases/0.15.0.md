# Zivion 0.15.0

新增阴历出生日期选择器。在输入页勾选“阴历”，点击“调整时间”，即可分别选择年、月、日和时分秒。

- 按年份显示实际存在的普通月和闰月，支持农历1900—2100年。
- 日期上限随月份变化。切入小月时调整到该月最后一天，并显示原因。
- 切换到没有所选闰月的年份时，改为同名普通月并提示。
- 填入时同步日期与闰月选项并保存草稿，重启后可继续使用。
- 取消或按返回键保留原输入；当前命盘保持原状，点击“起盘”才计算。
- 无效旧输入会明确提示，确认填入后才替换为选择器显示的日期。

新增7604项日期选择检查，覆盖730个官方日期、201年的月份列表、闰月与大小月变化、时分秒和无效变更保护。重新通过13185项公历换算检查和129项非闰月边界检查。

Android 9离线模拟器完成6组交互验证，并检查公历入口、1.3倍系统字体下的滚动和按钮可用性。验证包含填入后立即关闭、重新打开、保存前保留命盘和明确起盘。旧命例、笔记和历史全部保留；测试只新增1条合成历史。安装包升级签名一致，未增加权限。

选择器使用已有历表，排盘引擎与历表内容未修改。出生日期选择可以使用实际闰月；流月查询中的日时叠宫仍按非闰月校验，闰月和23点仅可换算预览。全范围逐日外部对照、更多实体设备和系统版本验证仍待补充。
