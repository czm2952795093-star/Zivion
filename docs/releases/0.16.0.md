# Zivion 0.16.0

新增大限与流年的流曜分布。切换至“大限”“流年”或“流月”后，点击“流曜分布”查看各宫星曜。

- 提供禄存、擎羊、陀罗、天魁、天钺、文昌、文曲、天马、火星、铃星、红鸾、天喜、咸池及“耗”共14类流曜。
- 流年按所查年份计算。流月可查看同一年的限年分布。
- 可单独复制流曜，也可勾选“盘面复制含流曜”，在盘面复制中附上分布。该偏好随重启保留。
- 未进入首限时显示提示。四化仍由各查询模式中的宫位选择控制。

流曜在独立详情页中查看。月、日、时流曜和日时四化仍待补充。

验证覆盖48项回归检查、1,440组流曜输入组合与4组 Android 9 交互。核对了切换年份、流月、复制、重启和旧记录保留。发布包延续上一版升级签名。
