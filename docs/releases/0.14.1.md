# 紫微星语复刻验证版 0.14.1

修复公历换算对话框中的旧结果残留与提示覆盖问题。

- 修改输入后立即清除旧农历结果和旧错误，提示重新换算，避免把上一日期的结果当作当前结果。
- 非法日期只显示错误，不保留旧换算结果；修正输入后可重新换算。
- 闰月、23点或命盘年龄范围限制阻止填入时，保留有效的农历结果，并另行显示原因，便于查看日期。
- 取消和填入失败保留当前命盘，正常日期仍可填入并在重启后恢复。

Android9/API28离线模拟器通过4组交互检查，覆盖输入修改、无效日期、错误修正、闰月/23点/年龄限制、普通填入和重启；升级前全部命例、笔记、历史均保留。REA安装和拉取核对通过，升级签名与0.14.0一致。

本轮只修改换算对话框显示逻辑；历表、CalendarLookup、日时与其他查询模型、本命引擎、备份/会话规则均未修改，继承0.14.0的730个官方日期对照与13185项程序检查，本轮未重复这些检查。未新增原版规则一致性或真机验证。

公历换算继续采用东八区钟表时间、午夜换日，不作太阳时修正。闰月和23点仍只支持换算；原版相应叠宫规则、流曜、其他精度与界面差异仍待完善。
