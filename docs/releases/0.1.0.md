# 紫微星语复刻验证版 0.1.0

这是可以安装、离线排盘的第一版，**还不是与原版完全一致的成品**。

## 已实现

- 安卓原生输入页和十二宫命盘，按 REA 提取的布局及原版实机画面还原基本结构。
- 公历、阴历、闰月、闰月换月选项；男女、经度、直接输入真太阳时。
- 十二宫、主星及辅星、四柱、命主身主、大限小限、四化去向。
- 点击宫位显示四化连线，再点查看详情；复制命盘文字。
- 命例保存、重新打开、历史记录；笔记新增、修改、删除；副标题、隐藏时间。
- 全部计算和记录保存在设备本地，安装包没有联网权限。

## 与原版的差异

原 APK 的原生排盘库会读取并比对应用签名。独立签名的验证程序取得了截断结果，个别调用发生原生异常，因此交付版没有使用这套库。

交付版使用 [iztro 2.6.2](https://github.com/SylarLong/iztro) 和 lunar-typescript 独立排盘，太阳时采用 [NOAA 方程](https://gml.noaa.gov/grad/solcalc/solareqns.PDF) 对应的近似天文模型。原版的特有规则仍须继续对照。

同一个实际样本：公历 1990-01-01 12:00:00、东经120°、男、东八区。

| 对照项目 | 结果 |
|---|---|
| 十二宫名称、宫干、大限 | 各12项一致；仆役统一显示为交友 |
| 14颗主星的位置 | 14项一致 |
| 各宫四化星及目标宫位 | 48项一致 |
| 四柱、命宫、身宫、五行局 | 一致 |
| 真太阳时 | 原版11:56:38，复刻版11:56:37 |
| 星曜亮度 | 62个共同星曜中46项不同，包含空白亮度；尚未校准 |
| 杂曜 | 有缺项、额外项及名称差异，详见对照数据 |

这些结论只针对这一个原版对照样本，不能推广成所有日期都一致。原版四化“力度百分比”、特殊亮度和杂曜规则、流运叠盘尚未重建。原版 AI、充值、更新、定位、六爻和其他工具页也未实现。界面的字体、间距、手势和部分控件仍有差异。

## 验证情况

- 在 Android 9 / API 28、x86_64、720×1280 模拟器实际安装运行；测试时关闭 Wi-Fi 和移动数据。
- 84组跨年份、时辰、性别组合通过命盘结构检查；另检查阴阳历等价、闰月、非法日期及真太阳时输入。
- 实际点击验证保存命例、重启后重新打开、笔记持久保存、无效日期拒绝、女性闰日及阴历排盘。
- APK 通过签名校验。未在实体手机及其他安卓版本进行兼容性验收。
