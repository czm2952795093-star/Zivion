# 紫微星语复刻验证版 0.13.0

新增“继续上次命盘”和输入草稿保留。整款APP尚未与原版完全一致。

## 本次变化

- 重新打开应用后，可继续上次成功生成的命盘，恢复本命/大限/流年/流月模式、虚岁/年份、月份、手选日时、所选宫位及四化连线开关。
- 尚未起盘的事项、时间、性别、经度及阴历/闰月等开关独立保留；继续旧盘不会把草稿内容写进旧盘。
- 恢复时重新计算原盘并校验全部查询参数，不重复添加历史。新起盘成功后才替换上次命盘；无效日期不覆盖旧盘。
- 损坏或不兼容的恢复参数会提示错误，原有命例、笔记和历史保留，可重新输入起盘。事项采用既有500字限制。

## 验证

恢复参数115项、日时145267项、年份1260项、流运1385项、来源486项、月份1238项检查通过。Android9/API28离线模拟器验证后台退出、强制关闭、恢复摘要一致、草稿隔离、无效日期、新盘替换与升级记录保留，逐项结果见rea-evidence/v13/session-ui-test.json。

安装包经过REA安装及拉取核对，升级签名与0.12.0一致。本命引擎及FlowState/MonthState/DayHourState不变，本轮未重跑全部原版本命样本；既有引擎对照结果明确继承。原版最近盘缓存来自已留存REA静态证据，不宣称原版全部查询状态及草稿行为一致。

## 限制

恢复缓存与草稿仅保存在本机，不随命例/笔记备份导出。草稿在离开应用时保存，不保证输入过程中系统突然断电仍保留最后一个字符。继续旧盘保持当时选择的查询年份，不自动跳到当前日期。

自动日时日期换算、闰月/大小月/子时边界、流曜、部分庙旺、太阳时精度、其他工具及原版界面细节仍待完善；尚无实体手机和更多安卓版本验证。手选日时仍只叠加宫位，不是完整日时排盘。
