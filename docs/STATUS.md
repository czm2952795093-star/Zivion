# 功能进展

当前测试版 0.16.1 支持在宫位详情中查看该宫的限曜和年曜。

0.15.1 中，本次统一闰月出生日期在输入、盘面、复制与读屏中的显示，完善隐藏出生时间与长日期换行。21项格式检查、4组安卓交互与1.3倍字体检查通过，全部记录保持原样。

0.15.0功能：新增阴历出生日期选择器，按农历1900—2100年提供实际月份与天数，可调整时分秒并保留草稿。取消不更改输入，填入不改变已显示命盘，点击起盘后计算。

已有离线排盘、本命/大限/流年/流月查询、手选日时叠宫、公历辅助填写、命例/历史/笔记、搜索、备份与恢复。

0.15.0中7604项日期选择检查、13185项换算检查和129项非闰月边界检查通过。Android 9完成6组交互与公历入口、1.3倍字体检查，升级签名和旧记录核对通过。详情见[测试说明](../tests/README.md)。

流月中的闰月与23点目前仅可换算预览；日时四化、月日时流曜、部分精度、工具页面、完整年份逐日外部验证及更多实体设备测试仍待完善。
